# AGENTS.md

## Local role

`tests/` proves repository contracts, deterministic derivation, public routes,
and boundary integrity. Focused operation behavior belongs in the nearest
mechanic-part test district; root tests cover shared cores, compatibility, and
repo-wide crosswalks.

## Editing posture

Derive package and part coverage from `mechanics/topology.json` and source
membership from `stats/source_home.manifest.json`. Pair a schema, source,
builder, or route change with the smallest durable negative and positive cases.
Keep generated, fixture, live, proof, and owner-acceptance evidence distinct.

## Hard no

Do not write tests that bless dashboard sovereignty, proof by volume, hidden
owner-repo assumptions, a central validation graph, or authority from counts.
Do not make a fixture or committed output stand in for live owner evidence.

## Conditional validation and closeout

Use root `VALIDATION.md` for route, source-home, topology, generated, and full
test selection. Report focused tests, root tests, skipped external or runtime
evidence, and which invariant remains owned by a stronger source.
