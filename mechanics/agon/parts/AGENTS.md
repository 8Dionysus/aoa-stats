# AGENTS.md

## Agon parts guide

Each child directory is one active, bounded stats operation. When a part is
selected, follow the package route, `PARTS.md`, and that part's README,
contract, provenance, and `VALIDATION.md` as needed.

Keep source payload local. A builder may cross the package boundary only to
publish the root generated output named by topology. Preserve stronger-owner
truth, candidate-only posture, and every declared stop-line. Do not add a part
merely because a filename contains `agon`; require a cohesive operation,
focused validation, and a clear output contract.
