# AGENTS.md

## Method Growth mechanic guide

This package implements the stats-side projection of the common
`Agents-of-Abyss/mechanics/method-growth` mechanic. Select the target profile or
operation through the source record and topology before editing.

The deterministic core is shared because Supersession Pruning consumes
normalized Candidate Lineage and landing receipts. Behavioral proof remains
part-local: each builder owns its schema, ordering, non-mutation, stability,
and non-inference checks. Add package proof only for an invariant neither part
can own.

Stats outputs are descriptive and weaker than named owner sources. Do not add
routing, proof, gate, workflow, or owner-acceptance authority.
