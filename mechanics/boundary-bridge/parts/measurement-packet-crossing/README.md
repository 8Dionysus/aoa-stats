# Measurement packet crossing

This part owns the repeatable crossing from an owner-local measurement
contract and packet into a compatible, weaker statistical result.

The shared source meaning remains under `stats/measurement-contract/`; local
questions and evidence remain in root `stats/` ports. This part carries the
pure semantic implementation and focused proof only. It does not discover
files, publish runtime state, render dashboards, or expose MCP.

The same crossing validates C10 `OutcomeReceipt` as content-minimized
measurement input. Task/source owners retain action and result facts;
`aoa-evals` retains attribution verdicts; `aoa-stats` owns only the strict
shape and pure compatibility rules. No receipt activates a writer, a memory
route, or a training loop.

The part also owns a descriptive
`aoa_stats_episodic_utility_aggregate_v0` packet over already-valid C10
receipts. It measures action change, terminal and delayed outcomes,
counterfactual coverage, accidental success, harm, and attribution posture.
It deliberately has no access-count input and carries no proof, ranking,
policy, lifecycle, semantic, or effect authority.

Phase 12 adds a descriptive
`active_organ_agent_local_federation_aggregate_v0` packet. It reconciles
promotion outcomes and exposes namespace blast radius, contamination,
private-to-shared leakage, degraded isolation, model portability,
consumer-zero residue, review minutes, saved re-grounding time, and net
operator burden. It cannot approve a promotion or issue a proof verdict.

The active contract is `CONTRACT.md`. `VALIDATION.md` points to the executable
proof owners without duplicating their commands.
